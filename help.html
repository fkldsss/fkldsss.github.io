🎨 Free Kaleidosss 操作說明

此文件說明所有按鍵、手勢與功能用途，方便您快速上手。

📌 滑鼠／觸控操作

操作功能
點擊貼紙選取貼紙（顯示虛線框），並將其提升至最上層
拖曳貼紙移動貼紙位置
拖曳右下角 ◢縮放貼紙（勾選 自由變形 可不按比例縮放）
長按 ⤢ = 等比鋪滿畫布
拖曳頂部 ●旋轉貼紙
雙擊貼紙切換鎖定／解鎖（鎖定後不可移動／縮放／旋轉）
長按鎖頭 🔓／🔒切換圖層（⚡ 圖示出現，貼紙轉為底層）

🔘 右側「指令中心」按鈕

按鈕功能
📸 Gallery將目前畫布內容儲存為一個「影格」（顯示於左側時間軸）
📋 Copy匯出所有影格為 JSON 文字（備份用）
🎞️ 匯出連續 PNG將所有影格匯出為 ZIP 壓縮包（內含 PNG 圖片序列）
🔓 全部解鎖／長按清空短按：全部貼紙解鎖
長按（0.95 秒）：清空畫布上「所有」貼紙（含鎖定）
⬆ 雙擊匯入指令庫從右側文字框匯入先前備份的 JSON 影格數據
📁載入 .txt 備份檔（自動填入文字框）

🎬 左側「範本播放器」

項目功能
⏰ 播放速度調整播放時每幀停留時間（0.4～10 秒）
▶ Play播放時間軸上的所有影格（循環播放）
■ Stop停止播放，回到目前影格
點擊影格卡片預覽該影格內容
雙擊影格名稱重新命名影格（最多 8 字）
右鍵點擊影格卡片複製該影格（插入在原影格下方）
拖曳影格卡片調整影格播放順序（拖曳後需點 📋 Copy 確認）

🗑️ 垃圾桶按鈕

操作功能
點擊 🗑️刪除目前選取的貼紙（若已選取）
長按 🗑️（0.95 秒）清除畫布上所有「未鎖定」的貼紙

⌨️ 鍵盤快捷鍵

按鍵功能
Delete 或 Backspace刪除目前選取的貼紙

📂 貼紙來源（下方選單）

分類內容
📂 上傳上傳自己的圖片（可複選，支援 Base64 儲存）
頭部／髮型／樣貌內建範例圖片
文字／繪製表情符號與繪圖字元

🎨 貼紙特效（動態效果下拉選單）

選項效果
呼吸／震動／旋轉／閃爍／浮動⋯為「目前選取的貼紙」套用動畫特效
清除畫面所有特效移除所有貼紙的動畫特效

🧩 其他重要功能

功能說明
鎖定貼紙點擊鎖頭 🔓 可鎖定貼紙（鎖定後不可編輯，且無法被長按垃圾桶刪除）
z-index 鎖定（⚡）長按鎖頭可切換，鎖定後點擊貼紙不會浮到最上層
自由變形模式勾選後，縮放貼紙時可任意拉伸（不保持比例）
自由邊界模式勾選後，縮放及拖拉貼紙都可任意拉伸到畫布外
瀏覽器記憶體上傳的圖片會自動儲存在 localStorage，重新整理網頁不會消失

📌 提示：長按時間皆為 0.15 秒（鎖頭）或 0.95 秒（清空按鈕）
